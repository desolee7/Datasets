# Инструменты для обработки изображений и парсинга

Набор инструментов для предобработки изображений, удаления дубликатов и парсинга изображений из поисковой системы Яндекс.

## Модуль Preprocessing

В этой папке находятся Jupyter ноутбуки для предобработки наборов изображений. Конвейер обработки включает:

### Возможности

- **Очистка от битых файлов** — поиск и удаление повреждённых / некорректных файлов изображений
- **Конвертация в JPG** — приведение всех изображений к единому формату JPG
- **Подсчёт количества изображений** — получение статистики по датасету
- **Удаление дубликатов** — поиск и удаление повторяющихся изображений с помощью хэшей (например, MD5, перцептуальные хэши)
- **Переименование файлов** — стандартизация имён файлов для удобной организации

## Модуль yandex_images_parser

Парсер для скачивания изображений из Яндекса. Поддерживает:

- **Поиск по текстовому запросу** — скачивание изображений по ключевым словам
- **Поиск по похожим изображениям** — поиск визуально похожих изображений
- **Поиск по уже скачанным изображениям** (файл `search_by_one.py`) — возможность использовать локальные изображения как источник для поиска похожих

### Очистка датасетов от визуальной разметки (Cleaning datasets)

Инструменты для удаления наложенной графики и разметки с изображений:

- **Удаление полупрозрачных областей внутри полигонов** — заливка полигональных областей с прозрачностью восстанавливается до исходного фона
- **Удаление контуров обводки** — очистка от границ и контурных линий (поддерживается работа с разметкой типов polyline)
- **Восстановление оригинальных пикселей** — интеллектуальная реконструкция областей, закрытых разметкой

Подходит для датасетов, где визуальная разметка (аннотации, полигоны, контуры) мешает обучению моделей или дальнейшей обработке.
