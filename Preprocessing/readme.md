# Датасет-пайплайн: Очистка и подготовка изображений

Набор Jupyter ноутбуков для подготовки датасетов изображений: очистка, конвертация, дедупликация и переименование.

## Структура пайплайна

Исходные данные (любые форматы)
↓

clean_and_convert.ipynb → Очищенный датасет (только JPEG)
↓

rename.ipynb → Переименованные файлы (img_000001.jpg)
↓

Phesh.ipynb → Удаление дубликатов (перцептивный хэш)
↓

count.ipynb → Подсчёт количества
↓

Предобработанный датасет

Предобоработанный датасет сохраняется в ```C:/datasets/hesh```


## Последовательность запуска

1. **clean_and_convert.ipynb** — первичная очистка
2. **rename.ipynb** — переименование в короткие имена
3. **count.ipynb** — проверка количества (опционально на каждом этапе)
4. **Phesh.ipynb** — удаление дубликатов
5. **count.ipynb** — проверка количества (обязательно для понимания объема собранных данных)

---

## 1. clean_and_convert.ipynb

**Назначение:** Создаёт копию данных, удаляет битые файлы и webp, конвертирует всё в JPEG.

**Вход:**
- `SOURCE_DIR` — путь к исходной папке с изображениями (любые форматы: PNG, WEBP, BMP, TIFF и др.)
- `DEST_DIR` — путь для сохранения очищенной копии

**Выход:**
- Копия исходной папки с сохранённой структурой
- Все изображения в формате JPEG
- Удалены WEBP файлы
- Удалены битые/повреждённые файлы
- Пустые папки удалены

**Особенности:**
- Конвертация с сохранением качества (95%)
- RGBA изображения обрабатываются корректно (белый фон)
- Прогресс-бар для отслеживания

**Настройка перед запуском:**
```python
SOURCE_DIR = "путь/к/исходной/папке"
DEST_DIR = "путь/к/папке/для/очищенной/копии"
```


## 2. rename.ipynb

**Назначение:** Переименовывает все изображения в короткие уникальные имена.

**Когда использовать:** После `clean_and_convert.ipynb` (на JPEG файлах).

**Вход:**
- `source_folder` — путь к папке с изображениями
- `dest_folder` — путь для сохранения переименованной копии

**Выход:**
- Полная копия структуры папок
- Все файлы переименованы в формат: `000001.jpg`, `000002.png` и т.д.
- Имена гарантированно уникальны (сквозная нумерация по всем папкам)

**Что делает скрипт:**

1. **Сканирует** все вложенные папки и собирает все изображения
2. **Сохраняет структуру** папок (подпапки остаются на своих местах)
3. **Переименовывает** каждое изображение в формат `XXXXXX.ext`, где:
   - `XXXXXX` — шестизначный номер (000001, 000002, ...)
   - `.ext` — оригинальное расширение файла


## 3. count.ipynb

**Назначение:** Подсчитывает количество изображений в папке.

**Когда использовать:** 
- После очистки и конвертации для проверки результатов
- После удаления дубликатов для контроля
- В любой момент для анализа датасета

**Вход:**
- `FOLDER_PATH` — путь к папке с изображениями
- `recursive` — учитывать ли подпапки (True/False)

**Выход:**
- Количество изображений

**Что делает скрипт:**

1. **Проверяет** существование папки
2. **Сканирует** указанную папку (и все подпапки, если recursive=True)
3. **Фильтрует** файлы по расширениям изображений
4. **Выводит** общее количество

**Учитываемые форматы:**
- `.jpg`, `.jpeg`, `.png`, `.gif`, `.bmp`, `.tiff`, `.webp`
- Регистр не важен (`.JPG` тоже учитывается)

**Параметры:**
- `recursive=True` — подсчёт во всех вложенных папках
- `recursive=False` — только в корневой папке

**Настройка перед запуском:**
```python
FOLDER_PATH = "путь/к/папке"
```

## 4. Phesh.ipynb

**Назначение:** Удаляет дубликаты изображений с помощью перцептивного хэша (perceptual hash).

**Когда использовать:** После `rename.ipynb` (на папке с короткими именами файлов).

**Вход:**
- `source_folder` — путь к папке с изображениями (рекомендуется после rename.ipynb)
- `dest_folder` — путь для сохранения копии без дубликатов
- `SIMILARITY_THRESHOLD` — порог сходства (0-64, по умолчанию 8)
- `SHOW_PREVIEW` — показывать ли визуализацию дубликатов (True/False)

**Выход:**
- Полная копия структуры папок
- Из каждой группы дубликатов оставлен только один файл (первый в группе)
- Визуализация найденных дубликатов (если SHOW_PREVIEW=True)
- Итоговая статистика

**Что делает скрипт:**

1. **Сканирует** все вложенные папки и собирает все изображения
2. **Вычисляет** перцептивный хэш для каждого изображения
3. **Сравнивает** хэши между собой (расстояние Хэмминга)
4. **Группирует** похожие изображения в дубликаты
5. **Показывает** визуализацию дубликатов (первые 3 группы)
6. **Создаёт** копию, пропуская дубликаты (оставляет по одному)

**Параметры порога сходства:**
| Порог | Режим | Описание |
|-------|-------|----------|
| 0-4 | Строгий | Только точные дубликаты |
| 5-7 | Средний | Умеренное сходство |
| 8-10 | Гибкий | Игнорирует водяные знаки, сжатие, небольшие изменения |
| 11-15 | Очень гибкий | Может ошибаться, объединяя разные изображения |

**Настройка перед запуском:**
```python
source_folder = r"C:/datasets/renamed"      # после rename.ipynb
dest_folder = r"C:/datasets/hesh"           # результат без дубликатов
SIMILARITY_THRESHOLD = 8
SHOW_PREVIEW = True
```
